# Cyclistic Bike-Share Data Analysis

## Project Overview
This project analyzes bike-sharing data to understand how casual riders and annual members use the Cyclistic bike-sharing service differently.

The goal is to identify usage patterns and understand differences in riding behavior between the two groups.

## Objectives
- Compare casual riders and annual members.
- Analyze ride duration and frequency.
- Explore weekday and monthly usage patterns.
- Examine bike type preferences.
- Identify patterns that could help improve membership strategies.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Analysis
The project involves:
- Data cleaning and preprocessing
- Feature engineering
- Exploratory Data Analysis (EDA)
- Data visualization
- Comparison of rider behavior

## Project File
- `cyclistic_analysis.ipynb`

## How to Run
1. Download or clone this repository.
2. Install the required libraries:
   `pip install pandas numpy matplotlib`
3. Open the notebook using Jupyter Notebook.
4. Run the cells to explore the analysis.
